Mengapa Web Ini Tidak Akan Pernah Membuat Akun Anda Terkena Banned?

Banned di Clash of Clans terjadi jika Anda membagikan akun (Account Sharing), memasukkan email/OTP Supercell ID ke situs pihak ketiga, atau memakai mod/bot ilegal di dalam aplikasi game. Web ini sama sekali tidak meminta login Supercell ID—melainkan hanya menggunakan Clan Tag & Player Tag publik (#...) atau jalur resmi developer.clashofclans.com yang disediakan langsung oleh Supercell.

Pengaturan Profil Klan & Impor Data Tag

Ubah nama & tag klan Anda, atau impor/ekspor seluruh database klan dalam format JSON maupun CSV secara gratis.

Panduan Hosting Gratis & Sinkronisasi Otomatis (Rp 0 Selamanya)

Anda bisa memakai web ini langsung sekarang juga, atau mengonlinekannya secara gratis agar seluruh Co-Leader dan member bisa melihat progres mereka:

Langkah 1 — Onlinekan Web Gratis di GitHub Pages / Netlify / Vercel

Cukup simpan 1 file HTML ini (index.html) dan unggah ke app.netlify.com/drop atau GitHub Pages. Dalam 10 detik web klan Anda langsung memiliki link publik gratis tanpa biaya sewa server.

Langkah 2 — Cara Kerja Tanpa Login & Anti-Banned

Member cukup melihat nama mereka di tabel. Anda sebagai Leader/Co-Leader dapat memperbarui data lewat tombol "Tambah / Update Member" atau menempelkan ekspor JSON dari bot klan publik seperti ClashPerk / ClashKing maupun portal resmi developer.clashofclans.com.

Langkah 3 — (Opsional) Otomatisasi Penuh dengan Cloudflare Workers Gratis

API resmi Clash of Clans membalikkan level Hero, Pet, Equipment, Town Hall, War Stars, Donasi, dan Capital Gold hanya dengan membaca #ClanTag. Anda bisa menghubungkan token dari developer.clashofclans.com ke Cloudflare Worker gratis (100.000 request/hari gratis) lalu tempel hasilnya ke kolom impor di samping.

CARA 2 — Sinkronisasi Otomatis Server Supercell (100% Real-Time)
